POND KICKOFF - SPORTS JERSEY DELIVERY
ระบบขนส่งเสื้อกีฬาแบบ Interactive Web Application

ไฟล์:
- index.html       หน้าหลัก/ภาพรวมระบบ
- shipping.html    สร้างรายการขนส่ง
- tracking.html    ติดตามพัสดุ
- network.html     Weighted Graph + Tree
- styles.css       รูปแบบเว็บไซต์
- script.js        JavaScript สำหรับการทำงาน

แนวคิด Discrete Mathematics:
1) Graph Theory: จุดขนส่ง = Vertex, เส้นทาง = Edge
2) Weighted Graph: ใช้เส้นทางเชื่อมโยงจุดขนส่ง
3) Tree: ศูนย์กลาง -> ภูมิภาค -> จุดปลายทาง
4) JavaScript: ใช้ข้อมูล Graph/Tree และการโต้ตอบกับผู้ใช้
